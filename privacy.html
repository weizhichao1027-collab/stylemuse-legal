StyleMuse Privacy Policy

Last updated: June 22, 2026

StyleMuse creates AI-generated outfit inspiration from photos and outfit descriptions selected by the user. This Privacy Policy explains what data is processed and how users can control it.

Data Processed

  • Full-body reference photos selected by the user.
  • Optional inspiration images selected by the user for try-on or styling guidance.
  • Optional outfit descriptions, style preferences, avoid notes, and other prompt text entered by the user.
  • Generated outfit images, styling notes, feedback, and saved looks.
  • The image generation API provider, endpoint, model, and API key entered by the user.
  • App Store purchase status for the 7-day trial and lifetime unlock.

How Data Is Used

Reference photos, optional inspiration images, and prompt text are used to create outfit inspiration. Style preferences are used to personalize prompts and styling advice. App Store purchase status is used to unlock trial or lifetime access.

StyleMuse is a Bring Your Own Key app. Image generation is performed through the API provider configured by the user. The app uses the selected provider, endpoint, model, and API key only to make generation or connection-test requests.

Storage and Retention

  • Generated looks, notes, feedback, style preferences, current outfit text, provider, endpoint, and model are stored locally on the device.
  • API keys are stored locally in the iOS Keychain.
  • Saved generated image files remain until the user deletes them in the app or removes the app.
  • Provider-side retention depends on the API service configured by the user. Users should review the selected provider's privacy policy and account settings.

Third-Party Processing

StyleMuse sends generation prompts and selected images to the image generation API endpoint configured by the user. The selected provider may process, store, bill, or log requests according to that provider's terms and privacy policy.

Normal remote provider endpoints should use HTTPS. Local-network HTTP endpoints are intended only for advanced users running a compatible image generation API on a trusted local network.

Tracking and Advertising

StyleMuse does not use the processed user content for third-party advertising or tracking. The app does not sell personal information.

User Controls

  • Clear the saved API key from Settings.
  • Clear the saved API key from the paywall privacy menu after the trial ends.
  • Delete saved looks on the device from Settings or the Saved tab.
  • Reset onboarding, API settings, language, and style preferences from Settings.
  • Export generated images to Photos only when choosing to save them.

Important Limits

AI outputs are styling inspiration only. They are not fit guarantees, body-shape assessments, health advice, or purchase guarantees.

Contact

For privacy or support questions, use the StyleMuse Support page.
