1. Quick start

  1. Open Settings → Generation provider.
  2. Choose a compatible provider and confirm its endpoint and model.
  3. Enter credentials from your own provider account, then save the configuration.
  4. Run Test API Connection. Resolve authentication, quota, or billing messages before generating.
  5. Open Create, choose a clear reference photo, select one preview, and generate your first look.

ImagineOutfit does not issue API keys or include image-generation credits. Provider setup, availability, models, quotas, retention, and charges are managed by the provider you choose.

2. If generation does not complete

Authentication failed

Create or copy a valid credential from the provider's official dashboard. Check that it has image-generation access and that no extra spaces were pasted.

Quota or billing blocked

Review the provider's balance, billing status, usage limit, and model access. App Store purchases do not pay provider API charges.

Endpoint or model rejected

Return to the provider preset, restore its recommended endpoint, and select a compatible image editing or generation model.

Request timed out

Keep the network available, reopen the app to allow supported tasks to resume, or try one preview before increasing the count.

Reference photo rejected

Use one well-lit person facing the camera. For a full outfit, include the knees and ankles and avoid an extremely narrow crop.

Result needs another pass

Review the face, skin tone, hands, pose, background, and clothing details. Adjust the prompt or reference and regenerate when needed.

3. Trial, lifetime access, and restoration

  • The seven-day full-feature trial is a free non-consumable App Store item. It never renews and never charges automatically.
  • Lifetime Access is an optional, one-time non-consumable purchase. It is not a subscription.
  • Both products unlock the app only. Image-generation credits and provider usage are separate.
  • To restore lifetime access after reinstalling or changing devices, sign in with the Apple Account that made the purchase and use Restore Purchases.
  • If an Apple purchase remains pending or fails, check the App Store payment method and purchase history, then try again.

Apple controls App Store payment processing, receipts, and eligible refunds. To request an Apple purchase refund, visit reportaproblem.apple.com ↗.

4. Camera, Photos, and saved looks

  • Camera access is used only when you choose to capture a reference photo.
  • Photos access lets you choose a reference or inspiration image and save selected results.
  • If permission was denied, open iOS Settings → ImagineOutfit and review Camera or Photos access.
  • Saved looks are local to the device. Delete a look in the Saved tab; delete exported copies separately in Photos.

5. Privacy and local data controls

API credentials are stored in the iOS Keychain. Generated looks and preferences are stored locally. Open Settings → Privacy & Local Data to clear credentials, delete saved looks, or reset local app data.

Resetting local data cannot erase a request already received by your provider or remove copies already exported or shared. Use the provider's account controls for provider-held data. Read the complete Privacy Policy for the exact data flow and retention details.

6. What to include in a support request

  • ImagineOutfit version and build number.
  • iPhone or iPad model and iOS/iPadOS version.
  • Selected provider, endpoint host, and model name.
  • The exact visible error message and the step where it appeared.
  • Whether Test API Connection succeeds.

You may include a screenshot after removing keys, personal photos, account identifiers, and other private information.
