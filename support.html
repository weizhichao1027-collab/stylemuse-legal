Trial and Lifetime Access

The free download includes a seven-day full-feature trial. The trial does not renew or charge automatically. After it ends, lifetime access is available as a single non-consumable In-App Purchase.

The trial and lifetime purchase unlock the app only. Image generation uses the API account you configure, and that provider may charge separately. Image-generation credits are not included.

If access does not update after reinstalling or changing devices, use Restore Purchases. Privacy and local-data deletion controls remain available after the trial expires.

Getting Started

Choose a provider in Settings, enter compatible image generation credentials, and test the connection. A configured provider and network access are required to generate an image.

Provider Help

  • Confirm the API key has image generation access.
  • Confirm the endpoint and model match the provider account.
  • Review the provider's quota, billing, and retention settings.

Privacy and Local Data

API keys are stored in the iOS Keychain. Generated looks and preferences are stored locally. Settings can clear the key, delete saved looks, and reset local state.

Report an Issue

Include the app version, iOS version, provider, endpoint host, model, and visible error. Do not include API keys or private images.
