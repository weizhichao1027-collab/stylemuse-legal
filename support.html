1. Getting started

  1. Download ImagineOutfit from the App Store on an iPhone or iPad running iOS 17 or later.
  2. Finish onboarding and enter the app. There is no ImagineOutfit sign-up screen.
  3. Open Settings → Generation provider.
  4. Choose a compatible provider, confirm its endpoint and model, then paste credentials from your own provider account.
  5. Save the configuration and run Test API Connection when the provider supports a read-only check.
  6. Open Create, confirm a clear reference photo, start with one preview, and generate.

ImagineOutfit does not issue API keys and does not include image-generation credits. A consumer chat subscription does not automatically include API access.

2. There is no ImagineOutfit account

ImagineOutfit does not create a user account, email login, or cloud profile. You cannot sign in, sign out, or delete an ImagineOutfit account because none exists.

Image generation uses the provider account you already have. Purchase restoration uses the Apple Account that bought Lifetime Access. Local looks live on that device until you delete them.

3. If generation does not complete

Authentication failed

Create or copy a valid credential from the provider's official dashboard. Confirm image-generation access and remove extra spaces, quotes, or the word Bearer.

Quota or billing blocked

Review the provider's balance, billing status, usage limit, and model access. An App Store purchase does not pay provider API charges.

Endpoint or model rejected

Return to the provider preset, restore its recommended endpoint, and choose a compatible image editing or generation model.

Request timed out

Keep the network available and reopen the app so supported tasks can resume. Try one preview before increasing the count. Local cancel cannot revoke a request the provider already received.

Inspiration image unavailable

Inspiration mode is shown only when the selected provider and model accept a second image. Switch provider or use a preset or written description instead.

Result needs another pass

Review the face, skin tone, hands, pose, background, and clothing. Adjust the prompt or photo and generate again. Output is inspiration, not a fit guarantee.

4. Free previews, Lifetime Access, and restoration

  • ImagineOutfit is free to download and free to browse and configure.
  • After you connect a compatible image API, you can save two generated-image previews. Only images that successfully save into your local collection use the allowance.
  • Generation from the third saved image requires Lifetime Access, a one-time non-consumable in-app purchase. It is not a subscription and does not auto-renew.
  • On 16 September 2026 the App Store listed Lifetime Access at USD 4.99 in the United States and CNY 38.00 in mainland China. Apple storefront prices can change.
  • Free previews and Lifetime Access cover app permission only. Provider credits are not included.
  • Resetting local app data does not restore the two free previews.
  • After reinstalling or changing devices, sign in with the Apple Account that made the purchase and tap Restore Purchases.
  • A previous 7-day trial product is no longer sold and is not a current offer.

Apple controls payment processing, receipts, and eligible refunds. Request an Apple refund at reportaproblem.apple.com.

5. Camera, Photos, and saved looks

  • Camera access is used only when you capture a reference photo.
  • Photos access lets you choose a reference or inspiration image and save selected results.
  • Local Network access is used only if you point the endpoint at a loopback development server.
  • If permission was denied, open iOS Settings → ImagineOutfit and review Camera or Photos.
  • For a full outfit, a well-lit person with knees and ankles visible usually works better than a tight crop.
  • Saved looks are local. Delete a look in the Saved tab. Delete exported copies separately in Photos.
  • There is no bulk closet import and no wardrobe inventory feature.

6. Privacy and local data controls

Open Settings → Privacy & local data to clear the current API key, delete saved looks, or reset onboarding, credentials, language, and Style DNA.

A reset does not restore free-preview usage and cannot erase a request already received by your provider. ImagineOutfit has no cloud export of your catalog. You can share or save individual images you already generated. Read the Privacy Policy for the full data flow.

7. Frequently asked questions

What is ImagineOutfit?
ImagineOutfit is an iOS and iPadOS app, also called 灵感穿搭, that turns a user's reference photo and a clothing idea into personalized AI outfit previews. It is live on the Apple App Store.
Is ImagineOutfit on Android or Google Play?
No. ImagineOutfit is an iPhone and iPad app. It is not listed on Google Play.
Does ImagineOutfit require an account?
ImagineOutfit does not create or require an ImagineOutfit user account. Image generation uses an API account that you create with the provider you choose.
How much does ImagineOutfit cost?
ImagineOutfit is free to download. After you connect a compatible image API, you can save two generated-image previews. The third saved generated image requires the optional one-time Lifetime Access purchase. There is no subscription.
Do the two free previews include image-generation credits?
No. The two free previews and Lifetime Access unlock permission inside ImagineOutfit only. Your chosen provider may charge for every API request, including the first two.
Which languages does the app support?
ImagineOutfit includes 14 interface languages: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, French, German, Brazilian Portuguese, European Portuguese, Italian, Russian, Arabic, and Hindi.
How do I delete my data?
Open Settings, then Privacy & local data, to clear API keys, delete saved looks, or reset local app data. The developer usually has no server-side photo or prompt record to delete because ImagineOutfit has no account backend.

8. What to include in a support request

  • ImagineOutfit version and build number from Settings → About.
  • iPhone or iPad model and iOS or iPadOS version.
  • Selected provider, endpoint host, and model name.
  • The exact visible error message and the step where it appeared.
  • Whether Test API Connection succeeds.

You may attach a screenshot after removing keys, personal photos, and account identifiers.
