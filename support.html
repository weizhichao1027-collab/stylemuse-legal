StyleMuse Support

Last updated: June 22, 2026

Getting Started

StyleMuse is a Bring Your Own Key AI outfit inspiration app. To generate looks, open Settings, choose a provider preset, enter your image generation API key, confirm the endpoint and model, and use the Test API Connection button before generating an image.

API Key and Provider Help

  • Check that the API key is active and has image generation access.
  • Confirm that the endpoint uses HTTPS unless you are intentionally using a trusted local-network API.
  • Confirm that the model supports image editing or image generation with an input image.
  • Review the selected provider's billing, quota, and retention settings.

Purchases

StyleMuse uses App Store in-app purchases for access: a free 7-day trial and a one-time lifetime unlock. The trial does not auto-renew. Provider API usage and billing are handled by the user's selected API provider, not by StyleMuse.

Privacy and Local Data

API keys are stored locally in the iOS Keychain. Generated looks and style preferences are stored locally on the device. Users can clear the API key, delete saved looks, and reset app data from Settings.

Report an Issue

If you need help, please open an issue on GitHub and include the app version, iOS version, selected provider, endpoint host, model name, and the visible error message. Do not include API keys, private photos, or private generated images.
