隐私政策

灵感穿搭是已上架的 iOS / iPadOS App，没有用户账号、广告系统、分析 SDK、崩溃收集 SDK 或图片生成后端。每次生成所用的照片、提示词和 API 服务商均由你选择。

生效及最后更新日期：2026 年 9 月 16 日

本页目录 运营者 处理的数据 权限 共享 保留 你的选择 你的权利 未成年人与跨境 联系方式

1. 运营者是谁

本政策适用于灵感穿搭（英文名称 ImagineOutfit）iOS / iPadOS App 及本公开网站。灵感穿搭由 Zhichao Wei 开发和运营，App Store 销售者显示名为「智超 卫」。如有隐私问题，请发送邮件至 weizhichao1027@gmail.com。

灵感穿搭采用自带密钥（Bring Your Own Key）模式。开发者不运营图片生成服务器，在正常生成流程中不会接收你使用的照片、提示词、生成图片或 API 凭证。

2. App 处理哪些数据

由你选择的内容

  • 使用相机拍摄或从系统相册选择的参考照片。
  • 可选的灵感图、服装描述、提示词、Style DNA 偏好、排除说明和反馈。
  • 生成图片、收藏造型、标题、分类和笔记。

这些内容用于准备你主动发起的生成请求、展示结果、与参考照片对比，以及在你选择时保存造型。App Store 隐私营养标签将「照片或视频」和「其他用户内容」披露为与你关联、用于 App 功能的数据，因为你选择的服务商可能将上述内容与其账号关联。

服务商配置

  • 你选择的图像 API 服务商、端点和模型。
  • 你输入的 API 凭证，包括腾讯云 SecretId 与 SecretKey 等成对凭证。
  • 恢复进行中任务所需的服务商任务标识及有限恢复信息。恢复文件不保存 API 密钥。

凭证按服务商和规范化端点来源隔离，保存在 iOS 钥匙串中，仅用于连接测试和生成请求的身份验证。腾讯云 SecretKey 只在本机用于签名请求。

设备端分析

App 可能在设备端处理面部、身体、手部关键点及人物分割，用于评估参考照片并帮助保留视觉细节。这些结果是临时的，不会保存为生物识别档案，也不会发送给独立的分析服务。

购买状态与免费预览次数

App 会在本地偏好设置和 iOS 钥匙串中保存已成功生成的免费预览图数量，因此重置本地数据不会恢复免费次数。Apple StoreKit 会提供永久使用权限非消耗型项目的已验证交易状态。App 不会将预览次数或购买历史发送到灵感穿搭账号或后端。购买处理遵循 Apple 隐私政策。

本机诊断

App 可能在本机写入简短诊断日志，记录服务商名称、截断后的请求标识、耗时、输出数量和错误类型。日志不包含 API 密钥、照片、提示词、响应正文、完整网址或本地路径，也不会发送给崩溃分析或统计公司。

支持沟通与网站

如果你发送邮件、拨打电话或创建 GitHub Issue，我们会接收你主动提供的信息以便回复。GitHub Issue 是公开的。本网站由 GitHub Pages 托管，GitHub 可能按照其隐私声明处理连接信息。本网站不使用联系表单、广告、分析工具，也不设置灵感穿搭自己的 Cookie。

3. 设备权限与系统接口

  • 相机：仅在你拍摄参考照片时使用。
  • 相册：用于选择参考图或灵感图，并在你要求时保存结果。
  • 本地网络：仅在你把端点配置为本机回环开发地址时使用。

App 使用本机 UserDefaults 和文件时间戳来保存偏好并管理收藏文件。这些系统接口不用于广告或追踪。灵感穿搭不包含广告 SDK、分析 SDK、崩溃收集 SDK、登录 SDK，也不进行 App Tracking Transparency 追踪。NSPrivacyTracking 为 false。

4. 图像服务商与数据共享

当你点击生成时，所选图片、提示词、Style DNA、已学习的反馈信号、设置和身份验证所需凭证，会从你的设备直接传输至你配置的服务商及端点。服务商可能将请求与你在该平台的账号关联，并按其条款处理、保留、记录、用于模型训练或计费。

图像服务商由你选择并自行签约，不是灵感穿搭的广告或分析合作方。提交内容前，请查看该服务商的隐私、保留、模型训练、处理地区和计费设置。

灵感穿搭不会出售个人信息，也不会向广告商、数据经纪商或跨 App 追踪服务共享用户内容。

5. 存储、保留与删除

  • 设备上的数据：生成造型、参考照片副本、笔记、偏好、受保护的收藏备份和临时恢复文件，会保留到你删除相应造型、重置本地数据或在适用情况下删除 App。
  • 凭证：API 凭证会保留在 iOS 钥匙串中，直到你主动清除或重置本地数据。简单卸载后钥匙串项目仍可能保留，因此建议先使用 App 内的清除或重置。
  • 免费预览次数：保存在本地偏好和钥匙串中。App 内重置不会清除该计数。
  • 系统相册：导出的图片会保留到你在「照片」中删除它们。
  • 服务商数据：保留和删除由你选择的服务商决定。
  • Apple 购买记录：由 Apple 按其政策保留。
  • 支持信息：只在解决请求、防止滥用、保留必要记录或履行法律义务所合理需要的期限内保存。

生成网络流程不会持久保存响应缓存、Cookie 或网址中的凭证。App 在验证服务商响应后，可能从返回的公开 HTTPS 地址下载生成图片。

6. 你的隐私选择

  • 自行决定拍摄照片或选择图片，并在生成前确认内容。
  • 在 iOS「设置」中更改或撤销相机、相册和本地网络权限。
  • 停止生成并清除保存的凭证，以阻止未来向服务商发送内容。
  • 删除单个收藏造型及其本地图片文件。
  • 通过「隐私与本地数据」重置新手引导、服务商设置、凭证、语言、Style DNA、参考照片副本、本地备份、恢复文件和本地网络缓存。
  • 在系统「照片」中单独删除已经导出的图片。
  • 使用服务商的账号控制功能管理已经发送给该服务商的数据。

本地重置会阻止较早的进行中任务结果被 App 保存，但不能撤回服务商已经收到的请求、删除服务商或 Apple 保存的记录、撤销服务商费用、恢复免费预览次数，也不能删除已经导出或分享的副本。

7. 你的权利

由于灵感穿搭没有账号和内容后端，开发者通常没有可以查询、更正或删除的服务器端照片、提示词、生成图片或账号记录。本机副本可通过上述控制功能访问和删除。

访问与删除

请先使用 App 内控制管理本机数据。若需要了解这些控制方式，或行使你所在地区适用的权利，请发邮件联系我们。

没有可注销的账号

不存在可以删除的灵感穿搭账号。清除凭证并删除收藏，即可移除 App 保存在本机的产品数据。

我们在设备上处理内容，是因为你要求 App 生成、保存或恢复造型。服务商侧处理遵循你与该服务商之间的约定。如需就本政策提出请求，请发送邮件至 weizhichao1027@gmail.com。

8. 安全、未成年人及跨境处理

灵感穿搭使用 iOS 钥匙串等平台保护措施，普通远程服务商端点必须使用 HTTPS。任何存储或传输方式都无法保证绝对安全，服务商账号安全也取决于你选择的服务商及配置的凭证。

灵感穿搭年龄分级为 4+，但没有加入 App Store 儿童类别。未成年人应在父母或监护人指导下使用；未经适当同意，不应将儿童照片提交给图像服务商。

你选择的服务商、Apple 或 GitHub 可能在你所在国家或地区以外处理信息，具体地点和保护措施见各自政策。选择服务商并要求 App 生成，即表示你指示 App 将所选内容发送至该服务商。

AI 结果仅供穿搭灵感参考，不构成合身程度、体型、健康、身份或购买结果保证。

9. 政策更新

当 App、数据流向或法律要求变化时，我们可能更新本政策。页面顶部的日期会同步修改，重大变化也会在适当情况下反映到 App 或 App Store 信息中。
