隐私政策

灵感穿搭没有用户账号、广告系统、分析 SDK 或图片生成后端。每次生成所用的照片、提示词和 API 服务商均由你选择。

生效及最后更新日期：2026 年 9 月 11 日

本页目录 适用范围 数据与处理方式 服务商与共享 保留与删除 你的选择 安全及其他说明 联系方式

1. 适用范围与运营者

本政策适用于灵感穿搭（英文名称 ImagineOutfit）iOS/iPadOS App 及本公开网站。灵感穿搭由 Zhichao Wei 开发和运营。如有隐私问题，请发送邮件至 weizhichao1027@gmail.com。

灵感穿搭采用自带密钥（Bring Your Own Key）模式。开发者不运营图片生成服务器，在正常生成流程中不会接收你使用的照片、提示词、生成图片或 API 凭证。

2. App 处理的数据

由你选择的内容

  • 使用相机拍摄或从系统相册选择的参考照片。
  • 可选的灵感图、服装描述、提示词、风格偏好、排除说明和反馈。
  • 生成图片、收藏造型、标题、分类和笔记。

这些内容用于准备你主动发起的生成请求、展示结果、与参考照片对比，以及在你选择时保存造型。

服务商配置

  • 你选择的图像 API 服务商、端点和模型。
  • 你输入的 API 凭证，包括腾讯云 SecretId 与 SecretKey 等成对凭证。
  • 恢复进行中任务所需的服务商任务标识及有限恢复信息。

凭证保存在 iOS 钥匙串中，仅用于向你配置的服务商进行连接测试和生成请求的身份验证。腾讯云 SecretKey 只在本机用于签名请求。

设备端分析

App 可能在设备端处理面部、身体、手部关键点及分割信息，用于评估参考照片质量并帮助保留视觉细节。这些结果不会用于识别你的身份，不会保存为生物识别档案，也不会发送给独立的分析服务。

购买状态

Apple StoreKit 会提供免费试用和永久使用权限这两个非消耗型项目的已验证交易状态及购买日期。App 使用这些信息解锁相应权限，不会将购买历史发送到灵感穿搭账号或后端。购买处理及相关记录由 Apple 按照其隐私政策管理。

支持沟通与网站

如果你发送邮件、拨打电话或创建 GitHub Issue，我们会接收你主动提供的信息，以便回复和解决问题。GitHub Issue 是公开的，请勿提交 API 密钥或私人图片。本网站由 GitHub Pages 托管，因此 GitHub 可能按照其隐私声明处理连接信息。本网站不使用联系表单、广告、分析工具，也不设置灵感穿搭自己的 Cookie。

3. 图像服务商与数据共享

当你点击生成时，所选图片、提示词、设置和身份验证所需凭证，会从你的设备直接传输至你配置的服务商及端点。服务商可能将请求与你在该服务商的账号关联，并按照其条款和隐私政策处理、保留、记录请求或计费。

图像服务商由你选择、配置并通过自己的账号使用，不是灵感穿搭的广告或分析合作方。提交内容前，请先查看服务商的数据保留、模型训练、处理地区、隐私和计费设置。不要使用你无法接受其保护措施的服务商。

灵感穿搭不会出售个人信息，也不会向广告商、数据经纪商或跨 App 追踪服务共享用户内容。如果未来有服务代表我们处理数据，我们会要求其采取符合本政策及适用法律的隐私和安全保护措施。

4. 存储、保留与删除

  • 设备上的数据：生成造型、用于对比的参考照片副本、笔记、偏好、受保护的收藏备份和临时恢复文件，会保留到你删除相应造型、重置本地数据或在适用情况下删除 App。
  • 凭证：API 凭证会保留在 iOS 钥匙串中，直到你主动清除或重置 App 本地数据。钥匙串行为由 iOS 控制，简单卸载 App 后凭证仍可能保留，因此建议先使用 App 内的清除或重置功能。
  • 系统相册：导出到系统相册的图片会保留到你在“照片”App 中将其删除。
  • 服务商数据：保留期限和删除方式由你选择的服务商管理。请使用该服务商的控制台、账号设置或支持渠道申请删除。
  • Apple 购买记录：购买记录由 Apple 按其政策保留。
  • 支持信息：支持沟通只在解决请求、防止滥用、保留必要记录或履行法律义务所合理需要的期限内保存。

生成网络流程不会持久保存响应缓存、Cookie 或网址中的凭证。App 在验证服务商响应后，可能从服务商返回的公开 HTTPS 地址下载生成图片。

5. 你的隐私选择

  • 自行决定拍摄照片或选择图片，并在生成前确认内容。
  • 在 iOS“设置”中更改或撤销相机和相册权限。
  • 停止生成并清除保存的凭证，以阻止未来向服务商发送内容。
  • 删除单个收藏造型及其本地图片文件。
  • 通过 App 的“隐私与本地数据”功能重置新手引导、服务商设置、凭证、语言、风格偏好、参考照片副本、本地备份、恢复文件和本地网络缓存。
  • 在系统“照片”App 中单独删除已经导出的图片。
  • 使用服务商的账号控制功能管理或删除已经发送给该服务商的数据。

本地重置会阻止较早的进行中任务结果被 App 保存，但不能撤回服务商已经收到的请求、删除服务商或 Apple 保存的记录、撤销服务商费用，也不能删除已经导出或分享的副本。

由于灵感穿搭没有账号和内容后端，开发者通常没有可以查询或删除的服务器端照片、提示词、生成图片或账号记录。如果需要了解这些控制方式，或行使你所在地区适用的权利，请发送邮件至 weizhichao1027@gmail.com。

6. 安全、未成年人及跨境处理

灵感穿搭使用 iOS 钥匙串等平台保护措施，普通远程服务商端点必须使用 HTTPS。但任何存储或传输方式都无法保证绝对安全，服务商账号和端点的安全性也取决于你选择的服务商及配置的凭证。

灵感穿搭没有加入 App Store 儿童类别。未成年人应在父母或监护人指导下使用；未经适当同意，不应将儿童照片提交给图像服务商。

你选择的服务商或 GitHub 可能在你所在国家或地区以外处理信息，具体地点和保护措施请查看各自政策。选择服务商并要求 App 生成，即表示你指示 App 将所选内容发送至该服务商。

AI 结果仅供穿搭灵感参考，不构成合身程度、体型、健康、身份或购买结果保证。

7. 政策更新

当 App、数据流向或法律要求变化时，我们可能更新本政策。页面顶部的生效日期会同步修改，重大变化也会在适当情况下反映到 App 或 App Store 信息中。
