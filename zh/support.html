1. 快速开始

  1. 打开设置 → 生图服务商。
  2. 选择兼容的服务商，确认端点和模型。
  3. 输入你自己服务商账号中的凭证，然后保存配置。
  4. 运行测试 API 连接。在生成前先解决身份验证、额度或计费提示。
  5. 打开创作，选择清晰的参考照片，先选择生成 1 张预览并开始第一次生成。

灵感穿搭不提供 API 密钥，也不包含图片生成额度。服务商设置、可用性、模型、额度、数据保留和费用均由你选择的服务商管理。

2. 如果生成没有完成

身份验证失败

从服务商官方控制台创建或复制有效凭证，确认它有图片生成权限，并检查粘贴内容前后是否包含多余空格。

额度或计费受限

检查服务商余额、计费状态、使用限额和模型权限。App Store 购买不会支付服务商 API 费用。

端点或模型被拒绝

返回服务商预设，恢复推荐端点，并选择兼容图片编辑或图片生成的模型。

请求超时

保持网络连接，重新打开 App 以恢复支持的任务，或先生成 1 张预览，再逐步增加数量。

参考照片不合适

使用光线清晰、正对镜头的单人照片。生成整套穿搭时，请包含膝盖和脚踝，并避免过窄裁剪。

结果需要重试

检查面部、肤色、手部、姿势、背景和服装细节；必要时修改描述或参考照片后重新生成。

3. 试用、永久使用与恢复购买

  • 7 天完整功能试用是 App Store 中的免费非消耗型项目，不会自动续费，也不会自动扣款。
  • 永久使用权限是可选的一次性非消耗型购买，不是订阅。
  • 两者都只解锁 App，不包含图片生成额度；服务商 API 用量另行计算。
  • 重新安装或更换设备后，请登录购买时使用的 Apple 账户，并在 App 中点击恢复购买。
  • 如果 Apple 购买一直处于待处理状态或失败，请检查 App Store 付款方式和购买记录后再试。

App Store 的支付处理、凭证和符合条件的退款由 Apple 管理。如需申请 Apple 购买退款，请访问 reportaproblem.apple.com ↗。

4. 相机、相册与收藏造型

  • 只有在你主动选择拍摄参考照片时，App 才会使用相机权限。
  • 相册权限用于选择参考图、灵感图，以及保存你选中的生成结果。
  • 如果之前拒绝了权限，请打开 iOS 设置 → 灵感穿搭，检查相机或相册权限。
  • 收藏造型保存在本机。可在“收藏”页删除造型；已经导出的副本需要在系统“照片”App 中另行删除。

5. 隐私与本地数据控制

API 凭证保存在 iOS 钥匙串中，生成造型和偏好保存在本机。打开设置 → 隐私与本地数据，可以清除凭证、删除收藏造型或重置本机 App 数据。

重置本地数据无法删除服务商已经收到的请求，也无法移除已经导出或分享的副本。服务商保存的数据需要通过该服务商的账号控制功能管理。完整数据流向和保留说明请阅读隐私政策。

6. 支持请求应包含的信息

  • 灵感穿搭版本号和构建版本。
  • iPhone 或 iPad 型号及 iOS/iPadOS 版本。
  • 所选服务商、端点主机和模型名称。
  • 完整的可见错误提示，以及问题出现在哪一步。
  • “测试 API 连接”是否成功。

你可以附上已经移除密钥、私人照片、账号标识等敏感信息的截图。
