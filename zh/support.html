1. 快速开始

  1. 在 iOS 17 或更高版本的 iPhone 或 iPad 上，从 App Store 下载灵感穿搭。
  2. 完成新手引导后直接进入 App，没有灵感穿搭注册步骤。
  3. 打开设置 → 生图服务商。
  4. 选择兼容服务商，确认端点和模型，然后粘贴你自己服务商账号中的凭证。
  5. 保存配置；若该服务商支持只读检查，请运行测试 API 连接。
  6. 打开创作，确认清晰的参考照片，先生成 1 张预览。

灵感穿搭不发放 API 密钥，也不包含生图额度。普通聊天会员不一定包含 API 权限。

2. 没有灵感穿搭账号

灵感穿搭不创建用户账号、邮箱登录或云端资料。因此不能登录、退出或删除灵感穿搭账号，因为账号并不存在。

生图使用的是你已有的服务商账号。恢复购买使用的是购买「永久使用权限」时的 Apple 账户。本机收藏会留在该设备上，直到你删除。

3. 如果生成没有完成

身份验证失败

从服务商官方控制台创建或复制有效凭证，确认它有图片生成权限，并去掉多余空格、引号或 Bearer 字样。

额度或计费受限

检查服务商余额、计费状态、使用限额和模型权限。App Store 购买不会支付服务商 API 费用。

端点或模型被拒绝

返回服务商预设，恢复推荐端点，并选择兼容图片编辑或图片生成的模型。

请求超时

保持网络连接，重新打开 App 以恢复支持的任务。先生成 1 张再增加数量。本机取消不能撤回服务商已经收到的请求。

无法使用灵感图

只有所选服务商和模型接受第二张图时，才会开放灵感图模式。可更换服务商，或改用预设、文字描述。

结果需要重试

检查面部、肤色、手部、姿势、背景和服装细节，修改描述或照片后再生成。输出只是灵感，不是合身保证。

5. 相机、相册与收藏造型

  • 只有在你主动拍摄参考照片时，才会使用相机权限。
  • 相册权限用于选择参考图、灵感图，以及保存你选中的结果。
  • 只有当你把端点指向本机回环开发地址时，才会使用本地网络权限。
  • 若曾拒绝权限，请打开 iOS 设置 → 灵感穿搭，检查相机或相册。
  • 生成整套穿搭时，光线清晰、能看到膝盖和脚踝的单人照片通常比过窄裁剪更合适。
  • 收藏造型保存在本机。可在「收藏」页删除；已导出的副本需在系统「照片」中另行删除。
  • 没有衣橱批量导入，也没有衣橱盘点功能。

6. 隐私与本地数据控制

打开设置 → 隐私与本地数据，可清除当前 API 密钥、删除收藏造型，或重置新手引导、凭证、语言和 Style DNA。

重置不会恢复免费预览次数，也不能删除服务商已经收到的请求。灵感穿搭没有云端目录导出。你可以分享或保存已经生成的单张图片。完整数据流向见隐私政策。

7. 常见问题

灵感穿搭是什么？
灵感穿搭是一款 iOS / iPadOS App，英文名为 ImagineOutfit，把用户的参考照片和穿搭想法变成个性化 AI 造型预览。现已在 Apple App Store 上架。
有 Android 或 Google Play 版本吗？
没有。灵感穿搭是 iPhone 与 iPad 应用，未在 Google Play 上架。
需要注册灵感穿搭账号吗？
不需要。灵感穿搭不创建用户账号。生图使用的是你在所选服务商处自行开设的 API 账号。
怎么收费？
App 免费下载。连接兼容 API 后可保存 2 张生成预览图。第 3 张成功保存的生成图需要可选的一次性内购「永久使用权限」。没有订阅。
2 张免费预览包含生图额度吗？
不包含。免费预览和永久使用权限只解锁 App 内生成权限。服务商可能对每次 API 请求收费，包括前 2 次。
App 支持哪些语言？
灵感穿搭界面支持 14 种语言：英语、简体中文、繁体中文、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语、欧洲葡萄牙语、意大利语、俄语、阿拉伯语和印地语。
如何删除我的数据？
打开设置中的「隐私与本地数据」，可清除密钥、删除收藏或重置本机数据。由于没有账号后端，开发者通常没有可删除的服务器端照片或提示词。
