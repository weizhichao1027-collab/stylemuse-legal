# ImagineOutfit Website

Public, bilingual GitHub Pages website for ImagineOutfit / 灵感穿搭. The iOS app is live on the App Store.

- `index.html`: English marketing page
- `about.html`: English product-facts page for people and assistants
- `privacy.html`: English Privacy Policy
- `support.html`: English support center
- `zh/`: Simplified Chinese versions of all four pages
- `assets/`: app icon, editorial image, screenshots, Open Graph image
- `llms.txt` and `llms-full.txt`: machine-readable official facts
- `sitemap.xml` and `robots.txt`: search-engine discovery
- `site.js`: mobile menu and support search

Preview locally:

```bash
python3 -m http.server 4179 --bind 127.0.0.1
```

Then open http://127.0.0.1:4179/
